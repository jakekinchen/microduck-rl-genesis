Make each experiment answer one question
The history supports a practical path: build the task contract, test the physics, establish a baseline, then train and diagnose measured failures.
Measure the motion you asked for
A backheel reward admitted turning around and toe-kicking. Later ball-property tests exposed failures hidden by aggregate scores. Use direction, contact, heading, stability and per-property buckets.
Keep a second simulator in the loop
The laser policy passed 5/6 Genesis cases but only 2/6 C MuJoCo cases before its command adapter was refined. Compare the same policy, case, model and action contract; preserve every failed result.
Separate seeing from steering
Current laser pursuit uses simulator target coordinates. Its locked head camera faces away from positive walking X at HOME. Pixel detection, frame geometry, latency and target loss need their own control-loop evidence.
Use the Mac deliberately
Measured CPU physics + MPS was faster for 64–512 environments; Metal + MPS won at 1,024. Benchmark total PPO iteration time. Keep rendering out of the training throughput measurement.
Unblock the right lane
Missing upstream policy history blocks that artifact’s admission. It does not block versioned first-party development. Keep release and physical gates separate from local learning.
Bring the useful parts of sim2claw
Use current-state projections, readiness checks, synchronized inspection and exact-action replay. Keep this project’s single-agent workflow and its existing training/evaluation boundaries.
