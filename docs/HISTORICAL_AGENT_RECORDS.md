# Historical agent records

The files in `briefs/`, `session-logs/`, `reviewer-messages/`, and
`manager-log/` are retained as immutable project history and evidence.

They describe an earlier Executor/Reviewer/Manager workflow that is no longer
active. They are not instructions for current or future agents, and no new
role-cycle records should be added. Current work is performed directly in one
Codex task, with the ordered backlog in `../TRAINING_ACTUALIZATION.md` and the
current boundary in `../GOAL.md`.
