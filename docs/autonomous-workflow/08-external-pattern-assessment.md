# External Pattern Assessment

Use this document when the user asks whether an external repo, scaffold, article, or framework should influence this workflow.

## Assessment Standard

Do not merge another framework by default. The local base remains Executor / Reviewer / Manager. An outside idea qualifies only if it fixes a concrete workflow blindspot that smart agents might still miss under long autonomous execution.
